# Image provenance

Every image on this site is a **genuine public-domain historical image** from
Wikimedia Commons (Kelvin died in 1907). There are no AI-generated images — the
decorative illustrations used in the first version were removed in September 2026
because they added nothing the text needed. Add an image only when it shows
something real that the page is talking about, and credit it here and in ch. 11.
